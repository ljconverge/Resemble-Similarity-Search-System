How to read these numbers

  • Recall = pairs LSH found ÷ pairs brute force found. Below 100% means some similar pairs never became candidates; exact verification cannot recover them.
  • Precision after the exact check is always 100% by design, so it says little about LSH. Candidates that were real matches shows how much checking LSH wasted. n/a means there was nothing to find at this threshold.
  • The S-curve threshold for {{ m.bands }} bands × {{ m.rows_per_band }} rows is about {{ m.approx_lsh_threshold }}%. Pairs well below it are rarely candidates, so a user threshold far below it lowers recall.
  • Speedup below 1× is normal for small collections: building signatures costs more than {{ m.brute_comparisons }} direct comparisons. LSH pays off as the number of documents grows, because brute force grows with n².
